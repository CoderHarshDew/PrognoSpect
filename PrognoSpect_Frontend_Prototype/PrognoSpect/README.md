# PrognoSpect Frontend Prototype

Project: AI World Model for Predictive Cyber Defence
SIH Problem Statement: SIH26153
Tagline: See the Threat Before It Happens.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- SVG network/attack graphs
- No React / TypeScript / Vite / Tailwind / backend / database

## Run
Open the `PrognoSpect` folder in VS Code and run `index.html` with Live Server.
Start from `index.html`.

## Important
This is a frontend demonstration. Risk, confidence, attack trajectory, calibration,
decision deadline, cost-aware actions, attacker tempo and explainability values are simulated.
No trained GNN, Temporal Transformer, World Model or SHAP implementation is connected.

## Simulation
The dashboard updates approximately every 20 seconds through `updateSimulation()`.
